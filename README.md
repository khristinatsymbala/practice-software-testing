# QA Learning Project — Toolshop

Навчальний QA-петпроєкт: Manual QA, API (Postman), SQL, Playwright + TypeScript + POM, AI-assisted QA через Claude Code, CI на GitHub Actions.

**Об'єкт тестування:** [Practice Software Testing](https://github.com/testsmith-io/practice-software-testing) від Testsmith. Застосунок запускається локально з окремого клону і **не входить до цього репозиторію** (див. його ліцензію). Тут — лише власні QA-артефакти.
